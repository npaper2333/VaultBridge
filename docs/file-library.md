# 接收文件与离线预览

Android 0.4.3 新增“文件”页；“文件传输”继续负责收发与任务队列。适用于 Android 8.0（API 26）及以上的手机和平板，鸿蒙设备需支持安装 Android APK；最低系统版本不代表所有机型和格式已经实测。

## 找到已接收文件

“文件”页可切换最近接收、最近查看，按文件名搜索并按类型筛选。这里只列本应用普通文件接收中已经完整校验并保存的项目，不混入 Obsidian 同步、发送来源、未完成任务或 `.partial`。列表记录不是整个手机存储的扫描结果。

最近查看以成功打开内置预览为准；交其他应用只表示“已请求打开”，应用无法确认外部阅读结果，不计为已阅读。

新版接收完成后记录文件提供器重命名发布后的实际 URI。旧任务可能只有完成状态、保存路径和哈希：应用按需在该任务原来授权的接收位置查找最终文件，核对大小与 SHA-256 后才补回可打开记录；不会把旧暂存 URI 当作最终文件。大文件首次核对可能需要时间，期间不改写原件。

文件移动、来源授权失效或内容变化时显示相应状态，按提示重新授权原位置或核对文件。不要为了消除记录错误删除原文件；目录索引异常也不回滚已经接收成功的文件，不把索引失败伪装成传输失败。

## 内置只读预览

| 类型 | 行为与上限 |
| --- | --- |
| 图片 | 单文件最多 32 MiB，按需要降采样；预览位图单边不超过 4,096 像素、总量不超过 4,194,304 像素。支持适应屏幕、1–8 倍双指缩放和单指拖动；动画按静态帧。具体编码支持取决于系统解码器，不能保证所有图片格式都可显示。 |
| PDF | 单文件最多 128 MiB、1–2,000 页，逐页渲染，可前后翻页或跳页，不缓存全部页面位图；单页同样受单边 4,096 和约 419 万像素限制。损坏、加密或系统不支持的文件显示错误，可选择其他应用打开。 |
| 文本 / Markdown | 最多 2 MiB，完整读取后显示纯文本；Markdown 显示源码。自动识别 UTF-8/带 BOM 的 UTF-16，UTF-8 无效时尝试 GB18030；也可手选 UTF-8、UTF-16LE/BE、GB18030。编码不适合时提示，不改写文件。 |
| Office / 压缩包 / 其他 | 交设备上能处理此类文件的其他应用打开；不内置 Office 引擎，不解压或自动安装。没有匹配应用时明确提示。 |

大文件传输上限仍是 8 GiB，能收到不等于能在内置预览中打开。超过预览上限时可使用其他应用，不截断内容冒充全文。图片使用限量读取、校验后的私有快照；PDF 对可定位读取的文件描述符先校验后直读，对不能定位读取的提供器使用限量私有副本。文本按上限读取并核对，预览都不写回原文件。

内置预览离线运行，不使用 WebView，不执行 HTML/脚本或加载远程内容。其他应用打开只授予临时读取权限，并排除 VaultBridge 自身，避免回到导入/发送入口；不会授予原文件写权限。外部应用的显示和后续行为由它自身决定。

## 记录、空间与验收

目录索引最多 20,000 项，索引与最近查看记录放在应用私有 `files/received/`，预览副本放在私有 `cache/previews/`，不自动清理；这些目录不是额外加密的文件保险库。超限时保留原文件与任务，不自动删除旧记录。系统清除缓存、清除数据或卸载可能影响副本、索引和授权，更新优先同签名覆盖安装。

没有更改 Obsidian 主库、传输批准、备份或同名保留规则。Windows 保持 0.4.2，本次没有 Desktop 0.4.3。新功能的构建/规则回归状态见 [公开验证记录](https://github.com/npaper2333/VaultBridge/blob/main/docs/testing.md)；真实手机/平板上的 SAF、图片解码、PDF 翻页、文本选择、手势和外部应用选择器仍按 [acceptance.md](acceptance.md)实测。Huawei MatePad Air 12 / HarmonyOS 4.2 是重点验收设备之一，不是专属适用范围。
