# 0.4.2 应用内更新方案

版本：0.4.2；日期：2026-10-14。应用内更新使用公开 GitHub Release 分发，两端保留旧文件、MIT/Nitro 和原有签名，不新增云端笔记存储、全局依赖或 CI。用户操作说明见 [updates.md](updates.md)。

两端启动后异步读取固定仓库的公开 Release 清单，选择比当前版本新的对应平台资产；含本项目预发布。界面显示版本、预发布标记、简短说明和“下载更新”，设置页可手动检查或关闭启动检查。没有网络时继续正常使用，检查失败不能显示“已最新”。不读取或发送笔记、目录、配对授权、设备名。

版本与文件名严格匹配：`vX.Y.Z`、`VaultBridge-Android-X.Y.Z.apk`、`VaultBridge-Desktop-X.Y.Z-portable.zip`。忽略草稿、旧版本、外部仓库/HTTP/任意主机下载地址。资产 SHA-256 取 GitHub digest；缺失时只提供发布页，不直接下载，也不从其他文件补猜校验值。限制响应与文件大小、超时、跳转次数，候选说明作为普通文字显示。

Android 点下载后完整校验，再核对 APK 包名、版本和当前安装签名，以只读临时 URI 拉起系统覆盖安装页。需要时由用户在系统页授予本应用安装来源权限；返回后须再次点击“安装更新”，重新核对后才打开系统安装确认页，不能静默安装。关闭/失败保留已下载文件，首次安装本版仍可手动传 APK。手机称呼修正继续保留。

Windows 点下载后验证完整 ZIP，拒绝穿越/链接/重复或异常条目，限量解包到新私有更新目录，要求 EXE 与同名配置完整。显示“切换到新版”并解释会停止当前分享；点击后启动新版并关闭当前应用，旧文件和共享的本地设置保留。不覆盖运行中的 EXE，不改系统设置。Windows 仍沿用当前无发行者证书状态，不宣称独立密码学发行者验证。

验证覆盖数字版本比较、草稿/平台/URL 过滤、损坏或超限清单、重定向边界、校验失败、ZIP 路径与限额、APK 身份核对、预览不联网和 UI 状态。构建/模拟测试不能替代手机系统安装、真实 Windows 切换及华为真机验收。发布前完成干净允许列表、签名、安装包/远端下载与标签源码核验。
