# 普通文件与笔记回传

普通文件传输从 0.4.0 起提供，不依赖 Obsidian，免费、无云端。两端需要网络可达，电脑保持分享运行。当前版本为两端 0.4.2；保留 EXE 旁同名 `.exe.config`，APK 直接覆盖同签名旧版，不要卸载。应用内更新从本版起提供，旧版需先手动安装一次，见 [updates.md](updates.md)。

## 电脑发到平板

1. 电脑“普通文件”选择文件或文件夹。文件夹保留相对目录；计算校验后生成发送清单。可以不选择 Obsidian 库直接启动分享和配对。
2. 平板“普通文件”选择独立接收位置，可记住并切换常用目录。
3. 获取电脑清单，勾选文件，确认位置后接收。ZIP 原样保存，Markdown 内容不改写。重新选择电脑清单会使未完成的旧清单任务停止，需要重新选取内容。

## 平板发到电脑

平板选择发送文件或文件夹，勾选内容，可填收件箱内相对子目录。电脑显示本批文件、总大小和位置，用户确认后才写入普通文件收件箱。普通收件箱不能放在当前电脑 Obsidian 库内；笔记入库使用下述回传入口。

发送前将所选内容暂存到应用私有空间，形成可复用的内容快照。后续原件修改不会加入本任务，需要重新选择。暂存阶段暂停时，已暂存的文件保留，当前未完成文件需要重新读取；来源授权失效时需要重新选择。发送不会删除来源。

## 平板笔记传回电脑主库

平板“电脑同步”→“选择平板笔记传回电脑”，从当前授权库逐文件勾选笔记和附件。目标默认为电脑当前 Obsidian 库根目录，也可填写 `来自平板/课程` 等库内相对子目录。所选文件原有相对目录继续保留。例如来源 `课程/实验.md`、子目录 `来自平板`，目标为 `来自平板/课程/实验.md`。

电脑逐批确认接收位置。相同内容跳过；同名不同内容编号另存，例如 `实验 (VaultBridge 1).md`，原有电脑笔记保留。不自动合并内容、修复回传链接、补齐附件、传播删除或覆盖主库。电脑 → 平板常规笔记同步继续使用原有备份、冲突和路径对应规则；回传只是用户主动选择的一批文件。

## 断网、暂停与重启

- 每块 4 MiB，先校验分块 SHA-256 再持久保存。断线重连核对任务和块清单，补缺失块；确认丢失时先询问接收端是否已保存该块。
- 网络故障按 2/4/8/15/30 秒退避，最多五轮重试，仍不通则保留等待状态。每次成功请求后的后续网络故障会重新获得重试窗口。
- 暂停按钮在工作期间可用。平板“普通文件”可查看任务、逐项继续、继续所有未完成任务或取消。取消仅改变状态，记录与文件保留。
- 如果电脑已开始校验并发布某个文件，平板暂停或连接断开后，这个已批准的文件仍可能在电脑完成；继续时核对电脑结果，避免重复保存。要阻止电脑后续发布，用电脑端的“撤销本批”。
- 重启平板后任务仍在队列；重启电脑后已批准任务和分块恢复。尚未批准的任务继续等待确认。电脑“接收任务 / 撤销本批”可查看结果或撤销后续写入，已保存文件保留。
- 完成的文件不重新发送。电脑身份/授权、发送清单、来源内容发生变化，或验证/空间/路径错误时，不自动无限重试；按错误说明重新建立任务或恢复权限。
- 原来的笔记获取也分块接收。暂停或失败后用“同步上次范围”，复用相同内容的已校验块；电脑笔记已变化则接收新版本。此类同步仍通过原有版本记录处理，不混入普通队列。

## 大小、存储与验收边界

普通文件单个最多 8 GiB，每批最多 64 GiB、20,000 个文件。笔记获取与 ZIP 解压仍保持原有 256 MiB 单文件/ZIP 512 MiB/解压总量 1 GiB 限制。隐藏配置、历史备份和链接不参与传输。

已校验块和完整暂存占用额外空间，另需接收目录的最终文件空间；应用不自动清理任务、块、缓存或备份。Android 普通接收只写本任务新建并持久绑定的 `.partial` 文档，暂停或失败后继续重写同一暂存；长度与 SHA-256 校验后，通过文件提供器重命名发布为原名或编号名。接收提供器必须支持重命名，不支持时保留暂存并明确报错，不把半成品写到最终原名、不标成功。Windows 使用目标旁暂存后改名落盘。不要把失败结果视为整批完成。

退出/系统结束应用后不会后台无限运行；重新打开后手动继续。清除应用数据或卸载会丢失私有任务和配对。发送、同步时避免同时编辑同一文件。

本机回归使用生成文件、实际 Java 客户端和 Windows 回环 TLS，包括 270 MiB 文件和人为切断的真实测试连接；不代表 MatePad 的 SAF、微信、后台行为或校园 Wi-Fi 已验收。真机步骤见 [acceptance.md](acceptance.md)。
