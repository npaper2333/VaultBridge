# 常见问题

## 需要付费或云账号吗？

不需要。应用免费开源，局域网接收无需互联网；电脑要开机并运行分享，平板才能获取新内容。已经接收的笔记可以离线读。

## 为什么 Obsidian 没看到笔记？

先核对两边是否使用同一个平板文件夹、导入模式是否将内容放入子目录、文件写入是否成功。必要时在 Obsidian 切回该库并检查文件列表。系统文件提供器和 Obsidian 实际刷新需要真机确认，不要通过复制删除整个库排错。

## 微信没有“其他应用打开”怎么办？

微信入口取决于当前版本和文件权限。下载 ZIP 后，到 VaultBridge 点“选择 ZIP”；解压与保存仍由应用完成。首次使用先检查临时库。

## 同一 Wi-Fi 为什么连接不上？

访客/校园网可能隔离设备。核对电脑端所选地址属于能与平板互通的网卡；可让两端连同一个自己可控的热点。防火墙提示只按可信网络授权。地址变化后用“更换连接地址”，仍校验证书；不要公开二维码或任意修改系统安全设置。

## 平板改过的笔记会被覆盖吗？

正常接收会比较上次接收基线和实际内容，保留本地修改并保存来源冲突版本；未改过的文件更新前先备份。在“备份与冲突版本”预览、采用或恢复。同步时尽量不同时在 Obsidian 编辑同一篇笔记。

## 为什么有些图片没同步？

选择部分文件/目录时，要把引用的图片、PDF 等附件一起选中。当前没有完整的 Obsidian 链接依赖解析器。跨目录引用和短链接歧义需要检查。

## 配色没跟随 Obsidian？

当前仅读取选中库默认 `.obsidian/appearance.json` 的基础模式和强调色，不运行主题 CSS/snippets，不支持自定义配置目录。提供器隐藏配置、未授权或配置损坏时显示原因并回退系统模式与紫色；从 Obsidian 返回后检测，也可手动刷新。

## 更新提示签名冲突怎么办？

GitHub Release 的同签名版本正常覆盖更新。第三方/自签 APK 使用不同密钥时，系统不能当作原应用更新。先保存需要的记录和备份，不要直接卸载唯一数据来源；优先下载本仓库 Release。

## 能双向同步、同步删除或自动清理吗？

当前不提供。电脑为主库、平板按需接收，保留旧内容与冲突；备份不自动删除。更改这些行为需要独立的规则和验证，不能靠关闭保护来实现。
