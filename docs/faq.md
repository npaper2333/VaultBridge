# 常见问题

## 需要付费或云账号吗？

文件传输不需要。应用免费开源，局域网接收无需互联网或云账号；电脑要开机并运行分享，手机/平板才能获取新内容。已经接收的笔记可以离线读。检查应用更新需要互联网；可选的 GitHub 反馈需要在浏览器登录 GitHub，提交内容公开。

## 为什么 Obsidian 没看到笔记？

先核对两边是否使用同一个平板文件夹、导入模式是否将内容放入子目录、文件写入是否成功。必要时在 Obsidian 切回该库并检查文件列表。系统文件提供器和 Obsidian 实际刷新需要真机确认，不要通过复制删除整个库排错。

## 微信没有“其他应用打开”怎么办？

微信入口取决于当前版本和文件权限。下载 ZIP 后，到 VaultBridge 点“选择 ZIP”；解压与保存仍由应用完成。首次使用先检查临时库。

## 同一 Wi-Fi 为什么连接不上？

访客/校园网可能隔离设备。核对电脑端所选地址属于能与平板互通的网卡；可让两端连同一个自己可控的热点。防火墙提示只按可信网络授权。地址变化后用“更换连接地址”，仍校验证书；不要公开二维码或任意修改系统安全设置。

## 平板改过的笔记会被覆盖吗？

正常接收会比较上次接收基线和实际内容，保留本地修改并保存来源冲突版本；未改过的文件更新前先备份。在“备份与冲突版本”预览、采用或恢复。同步时尽量不同时在 Obsidian 编辑同一篇笔记。

## 为什么有些图片没同步？

选择部分文件/目录时，要把引用的图片、PDF 等附件一起选中。当前没有完整的 Obsidian 链接依赖解析器。跨目录引用和短链接歧义需要检查。

## 配色没跟随 Obsidian？

先在“设置”检查主题色来源和深浅模式，它们独立生效；自定义颜色或手动深浅模式不会被 Obsidian 覆盖。选择跟随时，仅读取选中库默认 `.obsidian/appearance.json` 的基础模式和强调色，不运行主题 CSS/snippets，不支持自定义配置目录。提供器隐藏配置、未授权或配置损坏时显示原因并回退系统模式与紫色；从 Obsidian 返回后检测，也可手动刷新。Android 色块、滑杆与色值输入用法见 [外观设置](appearance.md)。

## 更新提示签名冲突怎么办？

GitHub Release 的同签名版本正常覆盖更新。第三方/自签 APK 使用不同密钥时，系统不能当作原应用更新。先保存需要的记录和备份，不要直接卸载唯一数据来源；优先下载本仓库 Release。

## 找不到检查更新，能自动安装吗？

旧 0.4.0 / Android 0.4.1 没有更新入口，先手动安装对应平台新版，可直接装两端 0.5.2。当前 Windows 在“设置”→“版本与更新”、Android 在“设置”→“更新”可手动检查、看说明和下载，也可关闭启动检查；旧 0.4.x 的入口为“外观与说明”或“设置与说明”。Android 授予来源权限并返回后需再次点“安装更新”。Windows 点击切换才停止分享并启动新版，不静默安装；更新器会跳过没有其平台资产的 Release。更新不上传笔记，断网不影响本机/局域网原功能，详见 [updates.md](updates.md)。

## 能双向同步、同步删除或自动清理吗？

常规笔记仍由电脑主库向手机/平板按需同步。0.4.0 起增加双向手动普通文件传输，以及 Android 主动勾选笔记传回电脑；两者均不建立自动双向笔记同步，不传播删除、不自动清理备份或传输缓存。回传需要电脑逐批批准，同名变化编号另存。规则见 [file-transfer.md](file-transfer.md)。0.5.2 的变化见 [版本说明](release-v0.5.2.md)，公开下载以 [Releases](https://github.com/npaper2333/VaultBridge/releases) 为准；历史版本保留。

## 明明以前传过，为什么没有隐藏？

“历史发送成功”不能证明文件现在还在目标位置。仅本次目标路径、大小和 SHA-256 均确认相同才隐藏；目标改变、内容变化、离线、旧端点或分享范围不足时保持可见。同内容在别处或同名另存也不会隐藏计划路径。隐藏时会取消对应勾选，设置与选择页的滑块保持一致，详见 [设置与建议交流](settings-feedback.md)。

## 在 App 里能私密提交建议吗？

0.5.2 已取消 App 内建议表单，按钮在外部浏览器打开固定 [GitHub 新 Issue 页面](https://github.com/npaper2333/VaultBridge/issues/new)。需要登录，提交后公开，由你在网页最终提交；不将打开页面当作已送达，不读取或上传旧草稿。希望私下交流可复制微信 **nitro1447** 后自行联系。不要在公开 Issue 中填写真实笔记、配对材料、密码或其他隐私；安全漏洞按 [SECURITY.md](../SECURITY.md) 报告。

## 为什么“文件”页没有显示某些文件？

它只列本应用普通接收完成的文件，不扫描整个手机，不包含发送来源、Obsidian 同步或未完成暂存。旧任务在原授权目录核对最终文件后才变成可打开项；授权失效、文件移动或内容改变时按提示处理，不会自动搜索全盘。查看规则和预览上限见 [file-library.md](file-library.md)。

## 普通文件和笔记回传的保存位置有什么区别？

普通文件使用独立接收位置：平板在系统选择器授权目录，电脑选择主库之外的普通收件箱。笔记回传写入电脑当前 Obsidian 主库，默认根目录，可填库内相对子目录；来源相对目录继续保留。两种位置、批准和目标说明分开显示，不因已有配对就自动允许写电脑。

## 断网会从头重传吗？

0.4.0 持久保存已验证的 4 MiB 块，重连核对后补缺失块；网络错误最多按 2/4/8/15/30 秒重试，仍失败可手动继续。普通文件从任务队列继续；常规笔记从“同步上次范围”继续。电脑清单、身份、来源版本变化或路径/空间/授权错误需要按提示处理，不能靠无限重试解决。

## 大文件会占用多少空间？

普通传输单文件最多 8 GiB、单批最多 64 GiB 和 20,000 个文件；原有笔记获取、ZIP 导入限制保持不变。分块、完整暂存和最终文件都可能占空间，发送前也会建立内容快照，应用不自动清理。Android 普通文件接收在所选目录新建并记录 `.partial` 暂存，长度与 SHA-256 校验后通过文件提供器重命名发布；不支持重命名则保留已有暂存并报错，只有最终发布成功才标为完成。

## 退出应用后能一直后台传输吗？

目前没有持续后台服务。系统结束应用或退出后任务保留，重新打开再手动继续；暂存前的来源授权失效需要重新选择。清除数据或卸载会丢失私有任务与配对，更新优先同签名覆盖安装。
