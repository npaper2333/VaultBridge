# VaultBridge Android 端 0.5.2（手机 / 平板，预发布）

两端统一为 0.5.2 预发布，新增集中设置、发送筛选/目标核验和 GitHub 反馈入口；Android 颜色窗口包含实际色块、滑杆和实时预览。详见 [设置与建议交流](settings-feedback.md)。

适用于 Android 8.0（API 26）及以上的手机和平板；鸿蒙设备需支持安装 Android APK，最低版本要求不代表所有机型已实测。将 `VaultBridge-Android-0.5.2.apk` 发到设备，按系统提示用同签名版本覆盖安装，不要先卸载。原有库授权、配对和版本记录继续使用，电脑端一起升级到 0.5.2 以使用完整对比功能。

界面称呼自动跟随完整屏幕尺寸：手机显示“手机接收位置”等，平板保留“平板”。仅调整静态界面文案，不改笔记或文件名。本文后续“平板”步骤同样适用于手机。0.4.1 本地称呼修正已并入本版，不单独发布 0.4.1 Release。

0.4.2 起支持应用内更新，当前入口在“设置”→“更新”。点“安装更新”后，APK 身份与签名核对成功才交系统确认；需要时按系统页授予 VaultBridge 安装来源权限，返回后再次点“安装更新”，不静默安装。启动检查可关闭，完整步骤见 [updates.md](updates.md)。

“文件传输”可切换独立接收位置、双向发送文件或文件夹、暂停和继续任务。单文件最多 8 GiB，分块 4 MiB；电脑需逐批允许接收。普通 ZIP 原样保存。“电脑同步”可选择手机/平板笔记回传，选择主库相对子目录，同名变化另存。完整步骤见 [file-transfer.md](file-transfer.md)。已有“文件”页可查看最近接收/最近查看、搜索筛选和离线只读预览，见 [file-library.md](file-library.md)。

## 发送前筛选

选定来源后，在独立窗口搜索、按类型筛选、勾选文件；图片右侧缩略图可以点开全图，预览与勾选分开。它只使用本次选择授权，不进入“最近接收”列表。

笔记回传先设置目标子目录，再运行“对比库”。普通文件仅核验本人原批准任务的实际落盘结果。只有当前目标路径和内容均确认相同才可隐藏，隐藏同时取消对应勾选；历史已传、变化、异名同内容和无法确认项继续显示。更换目标、修改来源或离线后不能沿用旧结果。对比不自动写电脑，发送仍需逐批确认。

## 这次的界面更新

固定晴湖书架布局，在设置中独立选择主题色来源和深浅模式。自定义主题色可点实际色块、拖动色相/饱和度/明亮度滑杆，或输入色值；下方立即预览主要按钮。无效输入不能应用，取消不保存。主页面、弹窗、输入、列表和扫码页统一为中性深浅背景与适度圆角；普通操作用灰色，少量同步、导入等主要操作使用强调色。文字按设备密度直接绘制。

灰色滚动条直接按主题绘制，列表缓存底色保持一致，关闭大块边缘发光。实际平板显示和快速滑动效果仍需真机检查。

## 首次使用

1. 在 VaultBridge 选择平板上已有的 Obsidian 库或目标文件夹；Obsidian 中选择同一目录。已有授权无需重新选，授权失效时到“库与目录”重新授权。
2. 电脑运行 VaultBridge 分享，两端连接同一局域网；平板扫码电脑二维码，或粘贴电脑端复制的配对文字。
3. 点“选择笔记并同步”选择范围；以后用“同步上次范围”，复用未完成文件的已验证块。电脑为主库，平板主动回传逐批确认，不自动同步删除。
4. 微信打开 ZIP →“用其他应用打开”→ VaultBridge；没有此入口时，在 VaultBridge 中“选择 ZIP”，由应用解压到当前库。

在“库与目录”可记住和切换多个位置、浏览、新建文件夹、重命名和移动，先看操作预览。同步、导入与更新继续保留备份和本地修改冲突。

外观配置缺失或无权限时回退系统深浅色和默认紫色，并说明原因；切库或从 Obsidian 返回后重新检测，也可手动“重新检测外观”。只读取 `.obsidian/appearance.json`，不修改或传输它，不解析主题 CSS。

## 建议与交流
