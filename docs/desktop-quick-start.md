# VaultBridge 电脑端 0.5.2（预发布）

两端统一为 0.5.2 预发布：Windows 增加集中设置和 Android 发送前对比所需的只读协议，保留接收逐批确认。设置中的反馈按钮直接打开公开 GitHub 新 Issue 页面；详见 [设置与建议交流](settings-feedback.md)。

“普通文件”选择文件/文件夹发给手机/平板，选择独立收件箱接收文件；接收逐批确认，同名内容变化另存。Android 笔记可主动回传到当前主库根目录或相对子目录。8 GiB 文件、4 MiB 分块和持久任务均为已有功能，用法见 [file-transfer.md](file-transfer.md)。

固定晴湖书架布局，在“设置”独立选择 Obsidian/自定义主题色及浅色/深色/系统/Obsidian 模式。Android 端支持 Android 8.0 及以上的手机和平板，鸿蒙设备需支持安装 APK；可覆盖更新，不先卸载。

**0.4.0 没有应用内更新入口，先手动解压新版并退出旧程序一次。** 0.4.2 起提供更新；当前在“设置”→“版本与更新”后台检查、显示版本说明、点击下载并校验。点击“切换到新版”才停止当前分享并启动新版，原文件与设置保留。启动检查可关闭，操作见 [updates.md](updates.md)。

0.3.2 修复圆角按钮实际重绘时的黑色边角，关闭主窗口后静默保留在托盘；托盘、窗口和 EXE 使用专用多尺寸图标。双击托盘图标或右键“打开主窗口”可以返回，右键“退出”完全关闭。

0.3.3 把页面/任务记录滚动条、地址选择框和下拉箭头统一为跟随深浅主题的灰色。原有滚轮、滚动条拖动、任务记录选择/复制和键盘选地址仍沿用原生控件。

0.3.4 修复快速滚动时闪现白条，滚动条始终使用当前主题的灰色。可以滚轮滚动、拖动滑块，也可聚焦滚动条后用方向键、Page Up/Down、Home/End 操作；任务记录仍能选择和复制。

背景、侧栏和普通操作使用中性灰，卡片与按钮有适度圆角。强调色集中在“开始分享”等主要操作；Obsidian 配置为黄色时该按钮显示黄色，配置为其他颜色时自动跟随。

1. 旧电脑端从托盘右键菜单“退出”；关主窗口会留在托盘。
2. 把电脑端 ZIP 完整解压到一个文件夹。
3. 双击 `VaultBridge-Desktop-0.5.2.exe`。保留旁边的 `VaultBridge-Desktop-0.5.2.exe.config`，高 DPI 显示需要它。
4. 主库、配对和勾选范围继续保留。选择跟随 Obsidian 的外观项目每两秒检测当前库配置；手动项目保持不变。
5. 到“设置”查看深浅模式、主题色与读取结果，可切换为自定义颜色，必要时重新检测 Obsidian 外观。

配置缺失、无效或无法读取时，使用系统深浅色与默认紫色。只读取基础外观，不修改或传输 Obsidian 配置，不解析 CSS 主题或自定义配置目录。两端分别跟随各自当前选择的库。

Android 的发送前笔记对比只读取电脑当前允许分享的范围；普通文件核验限本人原批准任务，不允许扫描任意电脑目录。范围不足或目标变化不能据此隐藏文件，旧历史成功也不是当前文件存在证明。对比不会扩大写入权限，仍需电脑逐批确认。

在“设置”→“联系与建议”点击“到 GitHub 提交建议”，或复制 Issue 链接。需要登录 GitHub，提交内容公开，由你在网页最终提交；不读取或上传旧本机草稿，也不预填文件或日志。私下交流可复制微信 **nitro1447** 后自行联系。

保持原生高 DPI 绘制，无需更改系统设置。原库、备份和旧安装包保留。电脑仍为主库，笔记回传必须主动选择和逐批确认，不自动同步删除。真实 Windows 更新下载与运行中切换仍需验收。
