# 无云端功能约定

日期：2026-10-10；更新：2026-10-11。状态：两端 0.3.4，固定晴湖布局、自动跟随库基础外观，已完成本机构建与回归，待华为真机验收。

电脑主库单向提供文件；平板默认手动选择范围并点击同步。局域网不需要互联网。电脑停止或关机时无法获取新版本，已同步笔记可离线使用。

Windows 桌面应用选择库、启动分享、展示配对信息与 QR、导出选定内容 ZIP；APK 选择 SAF 目标目录、扫码或粘贴配对信息、浏览电脑范围、下载增量文件、导入 ZIP、查看备份和恢复。

同步目标与 ZIP 合并目标必须显示给用户。首次同步同名但不同内容的文件视为冲突，不静默覆盖；用户可选择备份后使用电脑版本。以后只有目标仍等于上次同步版本时才自动更新。

应用保留恢复记录，不自动删除笔记。Windows 端不会接收平板回写。ZIP 新建批次保留相对路径，合并模式使用相同的内容比较和备份规则。ZIP 不会自动删除库中任何文件。

开发顺序：规则与协议 → Windows 端 → Android 端 → 核心验证与打包 → 真机验收。真机能力不可用本机编译或模拟测试代替。

多库状态独立、目录操作预览与中断记录、同步路径对应、明确引用修复、保留原库的笔记复制。按系统声明能力执行移动，不复制后删除；库位置切换不修改 Obsidian 配置。手动三风格切换已被自动外观检测替代；中性背景与圆角规则见 `appearance.md`，完整使用规则见 README。
