# VaultBridge 维护规则

本项目为免费、无云端的 Windows 主库 → Android 副本工作流，采用 MIT；第三方组件保留原许可。

## 目录与边界

- `desktop/`：C# / .NET Framework 4.8 Windows Forms；`android/`：Java 8 / Android API 26–35。
- `scripts/`：英文短横线命名的本地构建、测试和打包脚本；`tests/`：自建数据的测试源码。
- `docs/`：中文协议/使用/构建/验收说明；`licenses/`：原始第三方许可与 NOTICE。
- `tools/`、`work/`、`dist/`：本机构建依赖、临时数据/报告、产物，不提交。新文件用英文 ASCII 名，文本 UTF-8。
- 新目录和流程先约定用途再实现。不要上传真实笔记、配对文字/二维码、令牌、签名私钥或本机日志。

## 功能纪律

- 电脑只提供用户允许范围的常规文件；平板单向接收，不自动回写或传播删除。
- 同步/导入先验证路径、大小和 SHA-256；更新前备份，本地编辑保留为冲突；写入并校验成功后才更新管理状态。
- 不分享 `.obsidian`、历史备份、符号链接或隐藏配置。基础外观配置只能限量只读，不修改/传输或执行 CSS。
- 目录移动使用系统声明能力，先预览并记录中断状态，不以复制后删除替代；状态模糊时停止写入。复制到空库时原库保留。
- UI 固定晴湖布局：中性深浅大背景、真实适度圆角、少量主要操作强调色、原生清晰文字。原生白底之后覆盖着色不能作为快速滚动修复。
- 不自动生成发行密钥，公开构建使用 `build-android.ps1 -Unsigned`。发布 APK 由维护者用私有材料签名并验证，密钥不进源码/日志。

## 验证与发布

运行受影响的构建与 `scripts/test.ps1`；只有 Android 外观改动且 Windows 未改时，可用 `-SkipDesktopUi`。测试使用生成库与回环服务。

没有真机就报告构建和模拟/代码回归，不写真实 SAF、扫码、微信、触摸或跨显示器已通过。维护 CHANGELOG、README 下载入口、验证状态与第三方许可。

发布前核对干净源码文件、凭据排除、文档链接、签名与安装包哈希；安装包放 Releases，源码库不包含工具或构建目录。不得修改系统/全局配置或删除用户内容来解决构建问题。
