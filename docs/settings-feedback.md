# 设置与建议交流（两端 0.5.2 预发布）

手机、平板和 Windows 均保留晴湖布局、中性背景、适度圆角与少量主要操作强调色。相对此前公开版本的变化见 [0.5.2 说明](release-v0.5.2.md)。

## 外观和偏好

- **主题色**：跟随当前 Obsidian 库，或选择自定义颜色/输入十六进制色值。自定义主题色只用于主要操作，不把整个界面染色。
- **Android 自定义颜色窗口**：五个实际色块、选中标记和色相/饱和度/明亮度滑杆；色值和按钮预览同步变化。无效色值会禁用“应用”，取消不保存，可还原本次修改。
- **深浅模式**：浅色、深色、跟随系统、跟随 Obsidian；与主题色来源独立。例如可以采用系统深色，同时使用自定义黄色按钮。
- **显示选项说明**：可收起帮助文字；目录授权、覆盖影响和反馈隐私等必要提示保留。
- **已传文件显示**：Android 设置页和发送选择页共用“打标显示 / 隐藏已确认相同”滑块。Windows 不显示无实际效果的同名设置。
- **收到 ZIP 后自动导入**：Android 设置页控制是否立即处理；本次导入模式和目标仍在 ZIP 页选择。
- **启动检查更新**：设置页可关闭；断网不影响本地与局域网功能。

跟随 Obsidian 只读取所选库 `.obsidian/appearance.json` 的基础色值，不执行主题 CSS，不修改或同步配置。读取失败会显示原因并回退到系统深浅色与默认紫色；手动设置不被覆盖。

## 发送前查看和对比

Android 选择待发送文件后进入独立选择窗口，可以搜索、按类型筛选、查看图片缩略图并点开大图。勾选文件和打开预览是分开的操作。文件来源仍受本次选择授权限制，不会混进“最近接收”列表。

笔记回传先确定电脑接收子目录，再运行“对比库”。按相对路径、大小和 SHA-256 对比当前电脑允许读取的内容。结果区分“相同、内容有变化、当前范围缺少、别处有同内容、无法确认”。对比只读，不上传、覆盖、合并或删除文件。

**只隐藏当前目标路径和内容均已确认相同的文件。** 以前发送成功的记录仅作历史标记；断网、旧电脑端、授权不足、目标改变或来源变化时保持可见。部分分享清单缺少某条文件，不能据此推断整个电脑库都没有它。同内容存在别处也不代表计划路径已就绪。隐藏时会取消这些项目的选择，避免看不见却仍被发送。

普通文件通过本应用保存的成功回执重新检查原任务的实际落盘结果；不会为查重而扫描电脑任意目录。两端一起升级到 0.5.2 才能使用本版完整对比能力；旧电脑端仍可按原流程接收，无法核验的项目保持可见。电脑端对接收任务逐批确认的规则不变。

## 建议与交流

Android 在“设置”→“建议与交流”点击 **在 GitHub 提交问题或建议**；Windows 在“设置”→“联系与建议”点击 **到 GitHub 提交建议**。应用用外部浏览器打开固定的 [新 Issue 页面](https://github.com/npaper2333/VaultBridge/issues/new)，不预填建议、版本、日志或文件，也不附带目录、配对信息和旧草稿。没有可用浏览器时，按提示复制链接后自行打开。

**需要登录 GitHub，Issue 提交后公开，其他人可以查看。** 你在网页中填写并最终提交；打开网页不代表已提交，VaultBridge 不会显示 App 内送达回执。请先遮盖截图和示例中的笔记正文、库名、地址、配对二维码、密码或其他隐私。安全漏洞按 [安全说明](../SECURITY.md)单独报告，不把可利用细节直接发到公开 Issue。

希望私下交流，可以查看、复制作者微信 **nitro1447**（备注“VaultBridge 反馈”），欢迎 +v 交流。复制微信号不会自动发送消息；需要自行在微信联系。

0.5.0 / 0.5.1 本地验收版中的建议表单和历史草稿入口已取消。旧草稿文件保留，0.5.2 不读取、迁移或自动上传；若曾在旧版记录过内容，需要自行决定是否另行提交。私有作者端与服务模块未部署，不属于本版公开反馈链路，也不进入公开源码和公众安装包。

打开 GitHub 需要互联网，网页及登录由浏览器和 GitHub 处理；不影响离线笔记、ZIP 导入和可达的局域网传输。文件传输仍不经过云端，本版无需建议中转服务器。
