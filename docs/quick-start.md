# VaultBridge 0.5.2 快速上手（预发布）

本次两端统一为 0.5.2 预发布。集中设置、发送筛选/目标核验和 GitHub 反馈入口见 [设置与建议交流](settings-feedback.md)，版本变化见 [0.5.2 说明](release-v0.5.2.md)。

适用于 Android 8.0（API 26）及以上的手机和平板；鸿蒙设备需支持安装 Android APK。Windows 电脑主库 → 手机/平板 Obsidian 副本，另有普通文件双向互传和主动笔记回传。无云端笔记、无订阅费。本文“平板”步骤同样适用于手机，界面称呼按设备尺寸显示；不是所有机型都已实测。功能见 [普通文件与回传](file-transfer.md)和 [接收文件与预览](file-library.md)。

**旧 0.4.0 / Android 0.4.1 没有应用内更新入口，需手动安装一次新版，可直接装两端 0.5.2。** 0.4.2 起可检查对应平台的新版本、校验下载并由你确认安装或切换，见 [应用更新](updates.md)。

## 先连两端

1. 电脑先完整解压 ZIP，保留 EXE 旁的同名 `.exe.config`，打开 `VaultBridge-Desktop-0.5.2.exe`，选择 Obsidian 主库，点击“开始分享”。默认分享整个库，也可取消该选项并限定范围。
2. 将 `VaultBridge-Android-0.5.2.apk` 发到手机/平板覆盖安装。按系统提示为当前安装来源授权，保持系统安全检查。
3. 平板打开 VaultBridge，选择设备存储中的 Obsidian 库或目标文件夹。建议先用临时测试库。
4. 两端连接同一局域网；平板扫码电脑二维码。也可以在电脑复制配对文字，发到平板粘贴。
5. 平板“选择笔记并同步”，选择整个库、文件夹或具体文件。以后点“同步上次范围”。文件夹/全库模式会包含随后新增内容。

Windows 防火墙若询问，按自己的可信网络选择允许。程序不会自动修改防火墙。关闭电脑端窗口后会留在托盘；托盘右键可以停止分享或退出。

## 接收文件与预览

Android“文件传输”负责普通文件收发、暂停和继续；“文件”页显示普通接收完成项，可切换最近接收/最近查看、搜索文件名、按类型筛选。图片/PDF/文本与 Markdown 源码离线只读预览，Office/压缩包等交其他应用打开；不会扫描整机或把 Obsidian 同步混入列表。大小与权限边界见 [file-library.md](file-library.md)。

## 微信 ZIP 导入

- 微信打开 ZIP →“用其他应用打开”→ VaultBridge → 选择“导入 Obsidian 库”。也可以作为普通文件发送给电脑，不解压。库目标已设置且自动导入开启时，按当前规则导入。
- 如果微信没有这个入口，下载 ZIP 后在 VaultBridge 点“选择 ZIP”，随后由应用解压和保存。
- 新建批次：`微信导入/压缩包名称/`，保留目录和附件，同名批次加序号。
- 合并更新：放进所选库或指定子目录。首次同名不同内容视为冲突，不静默覆盖。
- 电脑端可以导出带版本清单的 ZIP。若要与联网同步管理同一批笔记，平板选择同一个目标库，使用合并模式，子目录留空。

两端一起升级到 0.5.2，才能使用完整的发送前对比与回执核验。直接安装同签名 APK 覆盖已有版本，不要先卸载；已有授权和记录继续使用。电脑先从托盘退出旧程序，再解压对应包并保留同名 DPI 配置文件。历史安装包保留。

## 发送前筛选与对比

Android 选择待发送文件后，可以搜索、按类型筛选、查看图片缩略图并点开大图；预览不会代替勾选。笔记回传先确认电脑目标子目录，再点“对比库”；普通文件仅重新核验自己原批准任务的落盘回执。

“打标显示 / 隐藏已确认相同”与设置页联动，只隐藏当前目标路径、大小及 SHA-256 均确认相同的文件，隐藏时取消对应勾选。历史已传、异名同内容、范围不足、断网或无法确认的文件继续显示。对比只读，发送仍需电脑逐批批准，不自动修改主库。

## 外观设置与库目录

两端固定晴湖书架布局。在“设置”独立选择主题色来源（Obsidian/自定义）及深浅模式（浅色/深色/系统/Obsidian），可收起常规功能解释，重要提示仍显示。Android 自定义颜色可选色块、拖滑杆或输入色值，并实时预览按钮；取消不保存。

选择跟随 Obsidian 的项目会读取各自当前库的 `.obsidian/appearance.json`；电脑每两秒检测，Android 回到前台或切库时检测，也可手动重新检测。配置缺失或无效时回退系统深浅色与默认紫色，并显示原因；手动设置不被覆盖。配置只读、不传输，主题 CSS 不参与检测。

大面积背景、侧栏、输入和普通按钮为中性黑白灰，强调色只用于开始分享、同步、导入等少量主要操作。卡片、输入和按钮采用适度圆角，电脑按当前 DPI 直接绘制文字。

电脑端 0.3.3 的页面/任务记录滚动条与地址选择框跟随深浅主题，深色界面没有原来的白底。滚动与选择操作仍由原生控件处理，不改变 Windows 系统主题。

电脑端 0.3.4 进一步修复快速滚动时的白条闪现，覆盖页面、任务记录和长目录列表；滚轮、滑块拖动、键盘和任务记录文字选择继续可用。

平板端 0.3.4 把主页面、弹窗、输入、列表和扫码页统一为同一深浅主题。普通操作用中性灰，少量主要操作使用库的强调色；滚动条为灰色，快速滑动不使用大块边缘发光，列表缓存底色与主题一致。实际平板上的显示和滑动效果按验收说明确认。

平板进入“库与目录”：

1. 管理已授权库位置：添加或切换库；每个库独立保存规则和历史。原库保留，Obsidian 要选择同一文件夹。
2. 浏览目录：进入文件夹、搜索当前目录、预览 Markdown、新建文件夹、设为 ZIP 合并目标。
3. 重命名 / 移动：先预览影响，确认后整理，维护同步对应；可备份后更新明确的标准链接。重名短链接及插件语法手动检查。系统不支持移动时该按钮禁用。
4. 查看同步目录对应：以后电脑更新、增加笔记，仍接收至平板整理后的目录。不会更改电脑主库。
5. 恢复中断目录记录：按实际位置恢复记录，无法确定时停止同步。
6. 复制笔记到另一库位置：目标需为空且没有版本记录。复制普通笔记、附件、对应和接收设置，校验后可切换；旧库、旧库版本保留，不复制 `.obsidian` 配置或历史备份。失败目标文件保留。

同步、导入和整理时尽量不要同时在 Obsidian 编辑同一库。恢复旧版后，目录变更造成的旧链接需要检查。

## 问题和建议

设置中的 GitHub 反馈按钮会在外部浏览器打开 [新 Issue 页面](https://github.com/npaper2333/VaultBridge/issues/new)。需要登录 GitHub，提交后公开；由你在网页中最终提交，打开网页不表示送达。App 不预填或上传旧草稿、笔记、日志和配对材料。私下交流可复制微信 **nitro1447** 后自行联系。

## 保护和恢复

平板没改过的笔记：先备份再更新。平板有改动：原笔记保留，来源版本放入冲突记录。到“备份与冲突版本”可以预览、采用来源版本或恢复旧版本。恢复前也会备份当前文件。

常规笔记仍以电脑主库为准。平板主动回传须选择文件并由电脑逐批确认，同名变化另存，不自动覆盖或同步删除。不会导入 `.obsidian` 等隐藏配置目录。备份在库内 `.vaultbridge/`，不自动清理；卸载应用会丢失私有配对和版本列表，但库内笔记与备份文件仍保留。

## 当前边界

- 电脑要开机并运行分享。电脑离线时，平板只能使用已同步笔记。
- 校园网/访客网络可能隔离设备；可换到自己可控的网络或同一个热点。电脑地址变化时，平板可更换连接地址，仍校验电脑身份。
- 选部分内容时，跨目录图片和附件需要一并选择。
- ZIP 最大 512 MB，解压总量最大 1 GB，单文件最大 256 MB，最多 20,000 条目；暂不支持加密、分卷和 ZIP64。
- 笔记获取与普通文件传输使用 4 MiB 分块续传；普通文件可到 8 GiB。ZIP 解压限制不变。同步期间避免同时编辑同一篇笔记。
- 临时缓存、备份不自动清理。按需使用系统应用管理清理本应用缓存，保留重要备份。

本版最终构建、签名和自动回归结果以发布时的验证记录为准。Huawei MatePad Air 12 / HarmonyOS 4.2 是重点验收设备之一，不是唯一适用设备；其系统安装、微信入口、扫码、持久目录授权和 Obsidian 实际刷新仍需实测，其他机型也应先做临时库验收。

程序为本地测试签名版本，不是应用商店发行版。分发包不含笔记、配对材料、SDK/JDK 或签名私钥。开源组件许可证见 `licenses/`。
