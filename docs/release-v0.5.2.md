# VaultBridge 0.5.2 预发布

版本日期：2026-10-17。Windows 与 Android 均为 0.5.2，Android 版本码 12。本文对应本版发行内容，下载以 [Releases](https://github.com/npaper2333/VaultBridge/releases) 为准。

**适用于 Android 8.0（API 26）及以上的手机和平板；鸿蒙设备需支持安装 Android APK。** Windows 使用 .NET Framework 4.8。手机和平板共用 APK。

## 相对已公开版本的变化

此前公开版本为 Android 0.4.3 / Windows 0.4.2。0.5.0 / Android 0.5.1 仅作本地验收，本版整合其功能并调整反馈入口后统一为两端 0.5.2。

- **集中设置与独立外观**：主题色可跟随 Obsidian 或自定义；深浅模式独立选择浅色、深色、系统或 Obsidian。常规说明可收起，授权和隐私等必要提示仍显示；启动检查更新可关闭。晴湖布局、中性背景、适度圆角和少量重要操作强调色保持不变。
- **Android 发送选择页**：搜索、按类型筛选、已传打标/隐藏快捷开关、来源图片缩略图与全图预览。打开预览与勾选分开，来源仅限本次选择授权，不加入最近接收列表。
- **按目标和内容核验**：笔记回传对比电脑当前允许分享的路径、大小与 SHA-256；普通文件仅重新核验本人原批准任务的实际落盘回执。只有本次目标路径和内容均确认相同才隐藏，并取消对应勾选。历史已传、异名同内容、范围不足、内容变化和离线未知项继续显示。对比只读，发送仍需电脑逐批批准，不自动覆盖、合并或删除主库。
- **Android 自定义颜色修复**：预设色不再被通用文字颜色覆盖成黑点，提供有名称的实际色块、选中标记、色相/饱和度/明亮度滑杆、色值校验与实时按钮预览。取消不保存，无效输入不能应用，弹窗可滚动。
- **公开 GitHub 反馈入口**：取消 App 内建议表单，按钮在外部浏览器打开固定 [新 Issue 页面](https://github.com/npaper2333/VaultBridge/issues/new)，无预填参数。需要登录，提交内容公开，由你在网页最终提交；打开网页不表示送达。微信 **nitro1447** 保留用于私下交流。旧本机草稿保留，不读取或自动上传。

最近接收/最近查看、接收文件的离线只读预览、普通文件互传、分块续传、备份和冲突处理是既有功能，本次继续保留，不重复列为新增。文件传输仍无云端，不需要建议服务器；私有作者端和服务模块未部署，不进入本版公开源码或安装包。

## 安装与升级

本版发行文件：

| 资产 | 用途 |
| --- | --- |
| `VaultBridge-Android-0.5.2.apk` | 可安装的手机/平板 APK。 |
| `VaultBridge-Desktop-0.5.2-portable.zip` | Windows EXE、同名 `.exe.config` 及说明/许可。 |
| `VaultBridge-0.5.2-local.zip` | 两端程序、使用指南、设置/传输/预览/更新/验收说明和许可。文件名中的 `local` 指本地运行分发包。 |
| `SHA256SUMS.txt` | 以上三个资产的 SHA-256。 |

Android 使用同签名 APK 覆盖安装，不先卸载；Windows 完整解压，保留 EXE 旁同名 `.exe.config`，手动运行前从托盘退出旧程序。两端一起升级以使用完整对比能力，原库、设置和历史产物保留。

0.4.2 起的更新器按对应平台资产提示新版；旧 0.4.0 / Android 0.4.1 需手动安装一次新版。下载校验与安装/切换仍需使用者点击，详见 [应用更新](updates.md)。

## 验证与边界

两端本机构建和完整自动回归通过：Windows 核心 192、原生 UI 144，实际 Java 互传/TLS 29 / 5；Android 设置/反馈兼容模型 52、发送选择 55、来源会话 21、颜色编辑 45，以及核心、目录、SAF 模拟、更新、最近文件、预览与配色等回归通过。数字不重复相加，逐项结果与边界见 [验证状态](testing.md)。

源码按允许列表导出，包内保留 MIT/Nitro 与第三方许可。发行校验使用 `SHA256SUMS.txt`；不将本机自动检查充当远端发布或真实设备通过的证明。

Android 真实 SAF、显示与触控、图片/PDF 解码、微信入口、扫码、外部浏览器和系统安装仍需设备验收；Windows 实际跨显示器、HTTPS 下载和运行中切换边界继续保留。Huawei MatePad Air 12 / HarmonyOS 4.2 是重点验收设备之一，不代表仅支持该设备或所有机型已通过。人工清单见 [acceptance.md](acceptance.md)。
